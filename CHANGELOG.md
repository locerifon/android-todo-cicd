# Changelog

Все заметные изменения в проекте **TodoApp** документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [2.1.12] - 2026-11-16

### Added
- Интегрирована система удалённого конфигурирования **Firebase Remote Config** для динамического управления функциями без перевыпуска приложения.
- Добавлен фича-флаг `new_feature_enabled` для управления отображением кнопки быстрого экспорта/шаринга задач.
- Добавлен дополнительный флаг `dark_mode_enabled` для активации экспериментального темного интерфейса.
- Реализована автоматическая генерация `versionCode` на основе счетчика коммитов в Git (`git rev-list --count HEAD`).
- Создан регламент реагирования на сбои и инциденты ([RUNBOOK.md](RUNBOOK.md)).

### Changed
- Автоматизирован процесс сборки релизного бандла AAB с динамическим инкрементом версии `2.1.XX`.
- Обновлена конфигурация Fastlane для автоматической привязки changelog к внутреннему треку Google Play Console (`track: internal`).

### Fixed
- Исправлено отображение статусов задач на экранах с высокой плотностью пикселей (xxxhdpi).
- Оптимизированы ProGuard/R8 правила минификации для предотвращения сбоев сериализации данных.

---

## [2.0.0] - 2026-11-10

### Added
- Базовая реализация интерфейса списка задач на базе Material 3.
- Интеграция с GitHub Actions для автоматической сборки APK и AAB артефактов при пуше в ветку `main`.
- Настройка цифровой подписи релиза через защищенный секрет `ANDROID_KEYSTORE_BASE64`.

### Changed
- Переход на `targetSdk 33` и компиляцию под Java 17.
