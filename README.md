## 1. Логика версионирования (Часть 1)

Для исключения конфликтов версий при загрузке в Google Play Console версионирование автоматизировано на уровне скрипта сборки `app/build.gradle`.

### Как формируются `versionCode` и `versionName`:
* **`versionCode`** (целочисленный код версии для Google Play):
  Вычисляется динамически на основе общего количества коммитов в ветке репозитория:
  ```groovy
  def getCommitCount() {
      try {
          def process = new ProcessBuilder("git", "rev-list", "--count", "HEAD")
              .redirectErrorStream(true).start()
          return process.inputStream.text.trim().toInteger()
      } catch (Exception ignored) {
          return 1
      }
  }
  ```
  Каждый новый коммит гарантированно увеличивает номер сборки на $+1$, что предотвращает отказ Google Play из-за дублирования `versionCode`.

* **`versionName`** (пользовательская версия):
  Формируется по шаблону семантического версионирования:
  $$\text{versionName} = \text{"2.1."} + \text{getCommitCount()}$$
  *Пример:* если в репозитории 12 коммитов, сборка получает `versionCode = 12` и `versionName = "2.1.12"`.

## 2. Управление функциями: Таблица Feature Toggles (Часть 3)

В приложении настроено удаленное управление функционалом через **Firebase Remote Config**. Новые возможности могут активироваться или отключаться удаленно на лету без необходимости повторной сборки и публикации в магазин.

| Название флага (Ключ) | Описание функционала | Значение по умолчанию | Условие отображения в UI |
| :--- | :--- | :---: | :--- |
| **`new_feature_enabled`** | Активация кнопки и карточки быстрого экспорта/шаринга списка задач (`cardShareFeature`) | `false` | Карточка скрыта (`GONE`). При значении `true` отображается блок быстрого шаринга. |
| **`stats_banner_enabled`** | Активация информационного виджета еженедельной аналитики продуктивности (`cardStatsFeature`) | `false` | Виджет скрыт (`GONE`). При `true` отображается карточка продуктивности со статистикой выполнения задач. |

### Сценарий «Выкатили — выключили»:
1. **По умолчанию**: флаги установлены в `false`, пользователи видят только базовый интерфейс задач.
2. **Включение**: в консоли Firebase Remote Config параметр переводится в `true` $\rightarrow$ приложение через `fetchAndActivate()` мгновенно отображает новую функцию на клиентских устройствах.
3. **Аварийное отключение**: при обнаружении аномалий или крашей флаг переводится обратно в `false` в течение 1 минуты, возвращая стабильное состояние без релиза новой версии.

## 5. Сборка и CI/CD
* **Локальная сборка AAB**:
  ```bash
  ./gradlew bundleRelease
  ```
* **Облачный пайплайн**: `.github/workflows/release.yml` срабатывает при пуше тега `v*`, автоматически генерирует артефакты и отправляет бандл с changelog через Fastlane в Google Play Console.
